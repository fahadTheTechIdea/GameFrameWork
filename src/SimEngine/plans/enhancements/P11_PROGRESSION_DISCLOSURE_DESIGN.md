# P11-A5 — contract-declared progression disclosure

## 0. Problem

TechnologySnapshot/ObjectiveSnapshot copy every prerequisite identity after only entry visibility. Objective predicates have predicate-DAG edges but no typed declarations of the content whose state they observe. An otherwise visible objective can therefore reveal progress from a hidden technology, prototype, condition or metric.

## 1. Goals

Use the original catalog, CompanyKnowledge, IVisibility, TechnologyService and ObjectiveSystem only. Require every IObjectivePredicate to declare a non-null immutable ObservationContent list of actual content aliases. Validate all declarations before Initialize, unused included. Existing native and independent providers implement that contract without an alternate coordinator. Do not replace hidden references with fabricated empty prerequisite lists.

## 2. Design

TechnologyService privately traverses the actual typed prerequisite DAG iteratively, observes metadata through original EntityObservation, and requires existing viewer visibility for the whole prerequisite closure before research admission or snapshot publication. This is discovery authorization, not learned completion. Earned work/knowledge stays authoritative and unchanged.

ObjectiveSystem privately traverses actual objective prerequisite definitions and captured predicate topology. It checks original visibility of each definition, predicate and declared ObservationContent before publishing a complete entry or evaluating a selected predicate. Public undisclosed objectives use existing NotFound. Internal lifecycle observations wait with typed objective.undisclosed, without running hidden callbacks. Existing deadlines, dependencies and effects remain authoritative. No new visibility store/cache, topology or fault owner.

KnowledgeVisibilityModule registers native typed objective and predicate targets using the existing generic KnowledgeVisibilityTargetDeclaration. Master-listed JSON explicitly chooses disclosure facts, policies and physically earned observation activities. No host visibility rules.

## 3. API

IObjectivePredicate.ObservationContent is required. ObjectivePredicateDef makes it abstract; no compatibility/default list. No snapshot fields or state payload change. Observer None remains explicit all-seeing tooling authority.

## 4. Files

Existing Technology.cs, Objectives.cs, ObjectiveContracts.cs, EnvironmentalMetrics.cs, KnowledgeVisibility.cs/Module.cs; existing independent predicate implementations and negative probe; one thin new driver/module plus explicit master/add-on content. Engine identity advances; no clock/protocol payload/schema owner changes.

## 5. Errors

Null, duplicate, unresolved, foreign or non-frozen observation aliases refuse before Initialize. Missing/dependent/cyclic references remain original content admission. Undisclosed entry admits no partial identity/status/deadline/progress facts. Provider callback failures retain the original World first fault.

## 6. Compatibility

No legacy path or default declaration. Migrate existing implementations in place.

## 7. Verification

ONE NEW exact bounded case. File-author independent predicate and native linked objectives; hidden transitive prerequisites and predicate input metadata; physical discovery/research; private saved twins/replay and revocation through ordinary ForgetKnowledgeCommand; no earlier/family/full suites. Compile once at completed slice, same-case repairs if necessary.

## 8. Risks

Repeated pure closure traversal adds read cost; allocation/soak gates remain open. A dishonest mod can omit its private CLR reads; this contract is explicit admission, not a CLR security sandbox. Whole-entry withholding avoids invented redacted prerequisites. Work/plan/job metadata, content-specific conditions/metrics, global deltas and arbitrary providers still need their original broad acceptance audits.

## 9. Scope limits

No Oil/Tycoon/platform changes or rendering. P11.acceptance.033 is broader than progression disclosure and stays open until all content menus/fog/deltas are proven. Protected G19 remains untouched; commit/push waits for the whole plan and goal.

## 10. Order

Migrate declarations; validate actual aliases; implement disclosure in original owners; author explicit JSON; run one exact proof; refresh tracker/evidence/source anchors without changing unproven original acceptance text.
