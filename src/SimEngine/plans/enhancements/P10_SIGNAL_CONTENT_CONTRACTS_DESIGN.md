## Problem and goals

At C8 entry, signal callbacks, typed gates, views, automation and quantity readers required
AutomationSignalDef. That dependency was removed through the existing descriptor contracts,
not another signal algorithm. M101 similarly removes duplicate live metadata verification
inside three reusable bindings: the original observation owner guards the complete entity
and preserves provider errors. Independent JSON descriptors and bindings use the same engine.

Introduce IAutomationSignalContent : IContentDefinition for kind/metric/unit/selected provider schemas. Keep IAutomationSignalDefinition as the distinct entity capability declaration contract. Extract the existing metadata parser into one AutomationSignalDeclaration value used by native/independent definitions. Move reader, typed snapshot construction and validation into one AutomationSignalContracts owner over the open content contract; delete native instance execution methods, not retain wrappers.
