## 0. Problem statement

P11 still lacks a non-tile sensor proof. `ISpatialSensor`, `SensorCoverage`,
`SensorVisibilityDef<T>` and `ControlledExecution<TDef>` already own the seams;
adding a second visibility, operation, clock or knowledge system would violate the plan.

## 1. Goals

1. Add an independently compiled engine-side point sensor through public contracts and master-listed JSON.
2. Actual inventory signals gate current sight, with ordinary physical hauling changing readiness.
3. Ordinary timed work moves the sensor, consumes real materials and earns a remembered observation.
4. Current sight, private metadata/entity visibility and remembered knowledge remain separate.
5. Save/load during hauling, travel and work continues deterministically; interleaved sessions stay isolated.

## 2. Design

`tests/ExtensionProof/PointSensorProof.cs` is an engine extension assembly, not the test driver.
`PointSensorDef` derives the existing controlled definition and implements `ISpatialSensorDefinition`.
`PointSensor` derives the original controlled execution owner and implements `ISpatialSensor`.
Detached point coverage uses fixed-point distance and the actual `ISpatialPresence` snapshot;
no tile conversion, game-size ceiling, retained visibility map or new system is introduced.
The existing inherited operation state/codec, signal evaluator, company visibility scopes,
motion/work execution and learned ledger remain authoritative.

`point-sensor.json` explicitly authors sensor prototype/start, distance bounds, material threshold,
signal, private visibility, physical survey requirement/effect and point reading.
The pure factory only selects files/modules/scenario seats. The one test drives normal route,
hold, operation and work commands and reads engine facts; it never moves entities, grants stock,
advances work or creates observations directly.

## 3. API surface

Public extension implementations only. Existing engine contracts/commands/views unchanged.
No core schema/build bump is warranted if core runtime source stays byte-identical.
