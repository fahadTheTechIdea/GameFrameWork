## Historical ER1 design

### 0. Problem

Upgrades relocates stock and retires the source but no EntityReplaced subscriber repairs live references. Workers retain retired home IDs.

## 1. Goals

Pure reference-owner admission before replacement; deterministic in-engine rebinding before retirement; exact native/external IWorker home edits; physical and saved continuation proof.

## 2. Design

Add IEntityReplacementReferenceOwner to Kernel. Existing service Providers and actual components enumerate participants once, in stable composition/entity order. Upgrades remains the sole replacement coordinator: observe admission, relocate stock, rebind actual references, validate unchanged stock/promises/clock/identity, then retire. Callback faults never return healthy success or fabricate rollback.

Existing WorkBoard delegates worker homes to WorkerHomeContracts. Extract one exact home-setter commit shared by ordinary Configure and replacement, preserving no-op and session guards. Held/job/motion state stays intact; physical return replans on normal Update. Independent providers participate through the new contract and existing Sync, not a new reference book. Internal purity hashing tolerates only the earned completion-before-retry transient; ordinary writes/hashes/loads still validate settled completion. A direct independent normal-hasher probe verifies rejection.
