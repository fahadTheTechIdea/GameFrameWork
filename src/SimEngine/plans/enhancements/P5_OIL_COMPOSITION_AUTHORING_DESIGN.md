and pull sets. No copied pool/flow/inventory/port coordinator. Other structure data unchanged.

OilOperationGateDef enumerates actual ITransformerDefinition metadata and validates each through its

explicit soft blockers. These are new selected game-content values (same native shape as the focused
fixture), not claimed historical timing parity. All six scenarios explicitly select it.
Existing graph/job/retry/clock owners remain responsible.
