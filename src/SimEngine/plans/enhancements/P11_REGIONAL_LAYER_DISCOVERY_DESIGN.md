## 0. Problem

Before D5, `KnowledgeVisibility.cs` admitted whole layer definitions only. `TileMapView` and the
public point provider consequently read every sample of an admitted layer. Native/private cursors
track layer membership, so learning a second area cannot invalidate a retained page independently.

## 1. Goals

1. Master-authored region/fact rules reveal only matching samples through the SAME visibility owner.
2. Actual company knowledge remains the sole saved learned ledger; no fog table/clock/survey scheduler.
3. Native tile and public non-tile readers refuse unknown requested samples without fabricated values.
4. Single-sample hidden writes leave company versions/chunks/pages unchanged; a newly known region
   invalidates once even when layer metadata was already known.
5. Physical machine activities consume materials/time, reveal successive areas privately, and restore
   deterministically during partial learning and queued ordinary sample commands.

## 2. Design

Optional `ISpatialSampleVisibility` extends the selected `IVisibility` owner, not a second service.
Provider snapshots represent sample locations using existing `SpatialSnapshot` and `ISpatialRegion`.
`LayerRegionKnowledgeVisibilityDef` authors one layer and explicit nonempty region/fact entries.
Entries reuse resolved `SpatialRegionDef` aliases and SAME `KnowledgeFactMatch` all/any matching;
linked spaces validate AFTER all definitions resolve, independent of document/section order. Known regions union
within a rule, while separately matching visibility rules remain conjunctive. Metadata admission
requires at least one known region. Ownership and linked content authorization remain mandatory.

Shared `SpatialLayerAccess` performs actual-provider/session checks before sample policy evaluation.
Stable opaque observation keys are derived from actual known region identities at the existing
end-Update/after-load refresh. Existing cursor caches retain those keys transiently, never learned
state or serialized values. Reads/save/hash do not refresh. Tile/point single-sample writes preflight
and publish only to viewers authorized for that actual sample. Whole bulk generation remains a
conservative full-visible-layer invalidation; exact bulk-difference privacy is a separately open gate.

Follow-up [D6 native bulk privacy](P11_BULK_LAYER_PRIVACY_DESIGN.md) now replaces that conservative
native Set/Fill write path with one exact sparse-diff/cursor owner.132 checks/ONE new bounded case,
clean2.229.0/save133/native tile view5. D5 physical/runtime case remains historical, NOT rerun.
External mod bulk/protected-cell matrices, dynamic vision/stale observations and broad gates stay open.

Full reads preflight every requested sample before writing outputs. Pages preflight their requested
samples before returning any cursor/version; mixed known/unknown pages refuse atomically. No artificial
world/region size limit, assumed coordinates, guessed defaults or compatibility parser.

## 3. API

`ISpatialSampleVisibility.CanSeeSample`/`CopyObservationKeys`; `SpatialLayerAccess.CanObserveSample`
and `CopyObservationKeys`; `layer_region_knowledge_visibility` JSON section. No host command to grant
knowledge. Physical learning uses existing knowledge effects and WorkBoard/WorkSystem DAG.

## 4. Files

## 5. Errors

Missing layer/region/fact, wrong space, duplicate region/fact, empty or malformed mode refuse content.
Unknown/missing/foreign/malformed viewers return Unavailable and cleared output; pages expose no
version/count. Unsupported sample geometry refuses, never substitutes tile or point coordinates.

## 6. Compatibility

No legacy reader, alias or fallback. Existing whole-layer rules remain explicit valid gameplay content,
not compatibility wrappers. New sample constraints compose through the same selected owner.

allocation/overflow/fault matrices, exact bulk invalidation and stale remembered observations remain
open. A remembered fact authorizes live regional reads; it is not a remembered copy of world samples.
