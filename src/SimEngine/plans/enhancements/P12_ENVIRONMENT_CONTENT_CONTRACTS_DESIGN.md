## 0. Problem statement

Standard/EnvironmentalMetrics.cs resolves concrete EnvironmentalMetricDef in its facade and
objective predicate despite an existing IEnvironmentalMetricDefinition contract. Direct definitions
cannot participate; provider validation lacks clock-control and consistent callback fault guarding.

## 1. Goals

1. Resolve actual immutable metric contracts everywhere, including unused definitions and objectives.
2. Remove the required native base; one strict policy declaration and one resource classification
   algorithm are shared by native and independently compiled definitions.
3. Retain the sole resource journal, objective lifecycle, physical work/stock, entity state and clock.
4. Guard actual validation/observation callbacks and reject reentry rather than recurse or substitute.
5. Prove real timed incident loss/cleanup, private cumulative/window facts, objectives, saved twins
   and replay through normal engine commands; refuse invalid metadata before Initialize.

## 2. Design

EnvironmentalMetricDeclaration owns explicit JSON unit/rate/window intent and actual unit resolution.
ResourceEnvironmentalMetricDeclaration owns the existing explicit resource/kind/cause classification
and journal observation algorithm; wrappers own no ledger or runtime state. Delete EnvironmentalMetricDef.
IEnvironmentalMetricDefinition.Unit is its actual IUnitContentDefinition. EnvironmentalMetricContracts
validates actual frozen catalog/unit aliases, positive quantum-exact windows and declared rate units.

EnvironmentalMetrics remains a stateless catalog facade apart from a transient reentry guard.
Composition visits all contract definitions before Initialize. Reads use existing EntityObservation
for the actual provider, clock/identity and existing entity facts; no duplicated guard/ledger/rollback.
The objective predicate resolves the metric contract and uses the same source for actual facts.
The original source and public view preflight World.RequireHealthyUpdate before their normal
invalid/missing/private shortcuts. Retained healthy detached facts remain valid historical facts;
cached live queries cannot report a healthy refusal or metric after the first terminal fault.

## 3. API surface

Existing metric/source/query/observation/view/objective contracts remain; unit metadata becomes the
existing content unit contract. New shared authoring declarations are public mod extension points.
No host commands, rendering, platforms or additional accounting store.
