## Proven behavior

- Old runtime types absent; master-listed definitions resolve native and unrelated public-only
  providers without a manager switch. Optional map/money and external no-inventory process work.
- Required named capabilities, actual profile support, ownership/index/count/home admission and
  private pure previews. 51 entries admit without arbitrary game-size limits; actual checked
  collection representation remains explicit. Retained queue snapshots are detached/immutable.
- Strict positive rational durations; missing/zero/negative/wrong-unit/old fields, negative costs,
  absent supply declaration, duplicate support and missing/invalid auto-repeat definitions refuse.
- Native elapsed batches consume through existing transactions once, retain progress on disable,
  resume real output and sequential production with exact input/output stock changes.
- Native auto-repeat is repeated timed execution, not an invented continuous process.
- Independent PulseTransformer owns timed work and creates actual engine entities through unchanged
  commands/manager. Entity.Update settles authored state; tests contain no process-completion logic.
- Multiple named capabilities can coexist; native/independent processes share pure engine gate
  evaluation. Disabled gate blocks before native material consumption/progress; restoration permits
  ordinary timed work. A touched gate mutation faults normal Update and prevents checkpointing.
- Completed output blocked by a removed explicitly selected home stays intact with NotFound;
  no fabricated home, prematurely created entity or repeated work.
- Actual native inventory-provider capacity/incompatibility cases preserve completed work/output
  admission. This proves current batch backpressure, not complete WIP/atomic multi-result semantics.
- Native checkpoint validation rejects invalid phase, empty/future progress, unsupported queued
  definitions and unearned completed-output phases. The manager uses the same validation on restore.
- Queued/working/disabled/completed/repeating/gated/home-blocked saved twins restore identical hashes
  and continue identically through interleaved engine Updates. New sessions share no process state.
- Mutating provider reads/checks and execution faults are detected; invalid/faulted state cannot
  Save. Read mutation guard is scoped to the touched provider entity, not all hostile cross-owner code.
