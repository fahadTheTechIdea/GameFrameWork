own/unlisted flags and canonical rules. Module composition, policy references and runtime evaluation
select actual frozen contract aliases. VisibilityTargetDef is deleted, not renamed or shimmed.

Definition/regional rules now resolve IKnowledgeSubjectDefinition rather than native KnowledgeFactDef.

KnowledgeVisibilityDeclaration alone reads/resolves policy flags/rules. The shared generic
KnowledgeVisibilityTargetDeclaration<T> alone reads definition/mode/facts, resolves actual target/
subjects, validates actual bindings and tests remembered all/any knowledge through the original ledger.
Independent Def policy/entity/activity definitions delegate there without native inheritance.
Native generic semantic specializations remain; they are not a required provider dependency.

KnowledgeVisibility remains the sole runtime owner. All loaded rule/policy actual aliases validate;
all policy rule lists validate canonical ownership/identity before Initialize. Only selected rules
validate current-world capabilities/space; unused definitions do not force another selected world.
Transient per-query PolicyFacts stage actual flags/rules for one call, never another authority/cache.
Existing EntityObservation guards actual callbacks/queried entity Sync/map scopes. A transient
evaluation flag refuses recursive entry and latches even swallowed recursion. Observation keys
stage before publication. No duplicate visibility/knowledge state, history, reservation, clock or codec.

The old KnowledgeContentContractTests factory gains generic authoring-only module/declaration/file/
scenario/world hooks. The new driver reuses that factory and canonical original point/construction
documents; no copied work/discovery/scheduling algorithm. Historical runtime cases compile only.
Public extension code is an engine-side registered mod, not host/demo gameplay.
